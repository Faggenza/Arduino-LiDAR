# Arduino-LiDAR 🤖

This university project aims to develop an Arduino-based platform to control the LiDAR Delta-2A from 3irobotix, enabling the scanning of small areas.

## Features 🔥

- **Arduino-LiDAR Integration**: Utilizes an ESP32 microcontroller to interface and control the LiDAR Delta-2A.
- **Small Area Scanning**: Designed for mapping and obstacle detection in confined environments.
- **System Integration**: Allows connection with other devices for applications such as robotics and environmental monitoring.

## Repository Contents 📕

- `src/`: Source code for the Arduino-LiDAR interface and visualizer.
- `docs/`: Technical documentation and user guides.

## Requirements 🔧

**Hardware**:

- ESP32 Devkit.
- LiDAR Delta-2A by 3irobotix.
- Voltage level shifter 5V/3.3V.

**Software**:

- Arduino IDE for programming the microcontroller.
- Python visualizer
  
## Usage 🚀

After installation, the system will perform scans of the surrounding area using the LiDAR. The collected data can be used to create environmental maps. Using the visualizer scan map of surroundigs is created.
